# 최지우 UX/UI 포트폴리오

복잡하게 분산된 정보를 명확한 사용자 흐름으로 구조화하고, 실제 화면과 반응형 웹으로 구현한 UX/UI 포트폴리오입니다.

## 프로젝트

### 당근부동산 APP REDESIGN

초보 임차인이 안전하게 매물을 찾고 방문·상담·계약 준비까지 이어갈 수 있도록 정보 구조와 화면 흐름을 개선한 프로젝트입니다.

- UX 리서치 · 벤치마킹 · 페르소나 · 사용자 여정맵
- 정보구조 · 와이어프레임 · UI 디자인 · Figma 프로토타입
- [프로젝트 보기](https://jwc95090-hash.github.io/portfolio_choijiwoo/karrot-portfolio.html)
- [개선 전·후 프로토타입](https://karrot-ux-compare-choijiwoo.jwc95090.chatgpt.site/)

### TRIPPICK 캠핑 예약 + 호스트센터

초보 캠퍼가 탐색부터 준비와 예약까지 한 흐름으로 이용할 수 있도록 설계한 반응형 웹 서비스입니다.

- 공공 캠핑장 데이터, 지도, 찜하기, 소셜 로그인
- 캠핑 안내 영상과 호스트센터 대시보드
- [사이트 보기](https://jwc95090-hash.github.io/trippick-site/)
- [프로젝트 보기](https://jwc95090-hash.github.io/portfolio_choijiwoo/trippick-portfolio.html)
