- 사용자 리뷰와 경쟁 서비스 분석을 통해 매물 탐색 과정의 핵심 불편을 정의했습니다.

- Figma 프로토타입을 제작해 개선 전·후 사용자 흐름과 UI를 비교했습니다.

TRIPPICK 캠핑 예약 + 호스트센터

캠핑 초보자가 필요한 정보를 쉽게 비교하고, 탐색부터 예약까지 자연스럽게 이어갈 수 있도록 설계한 캠핑 예약 반응형 웹 프로젝트입니다.

- 지역·일정 검색 → 캠핑장 비교 → 상세 확인 → 예약으로 이어지는 User Flow와 정보 구조를 설계했습니다.
- 캠핑장 선택에 필요한 시설·위치·준비 정보를 쉽게 비교할 수 있도록 카드와 상세 화면의 정보 위계를 설계했습니다.
- 예약·매출·리뷰 정보를 빠르게 확인할 수 있도록 호스트용 관리자 대시보드 UI를 별도로 설계했습니다.
- 실제 서비스 형태를 확인하기 위해 공공 데이터, 지도, 로그인 기능 등을 적용한 웹 데모를 제작했습니다.
